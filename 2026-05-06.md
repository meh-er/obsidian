### i)
These endpoints do not meet appropriate REST design conventions for endpoints.
The GET endpoint contains a verb, not a noun, and a singular 'order', when it is better practice to use plurals. Further it uses 'create' which would be wrong anyways for a GET endpoint, that should only be returning a response and not changing the state of the server.

The POST endpoint is also wrong, it contains 'delete', which should be completed with the HTTP method DELETE, because POST should be used to create new resources not delete old ones. Further, 'delete' should not be in the endpoint at all, for deletion it should just use the noun 'orders' and take in the id 12 to be deleted, not as a path variable but as a piece of data {12}.
