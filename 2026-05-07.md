$MAC(K,M) = H(M) ⊕K$

Attacker knows: $M, H(M) ⊕ K$

attacker can herefore compute $H(M)$ 
attacker can therefore compute $H(M) ⊕ K ⊕ H(M)$

attacker can therefore use $K$ to compute $MAC' = H(M') ⊕ K$ which will still be verified.

$MAC(K,M) = H(K || M)$
attacker knows: M, H(K||M).
Attacker wants to compute H(K || M || Padding || X).
Since key is first, and there is no size specified for M, attacker can compute H(H(K||M)),P || X) which works instead of adding to the end of a hash, and will make a hash out of K,M,P,X in order. this will still pass as it contains K  and M, and the rest will simply be considered padding.
