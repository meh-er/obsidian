A chat application project helps you understand how two users or computers send and receive messages using a network.
Tools and Technologies Used:
* Python
* TCP/IP Protocol
* CLI

Steps
-  Set up a server script that 'listens' for incoming connections on a specific port.
- Create a client script that connects to the server using its IP address
- Add a loop so the client can send messages and the server can receive and display them.
- Test the chat tool by running the server on one computer and the client on another computer connected to the same Wi-Fi network
