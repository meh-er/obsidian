LIST COMPREHENSIONS
Use when:
- transforming each element in a list
- filtering
- combining two lists
Use map or filter when:
- transformation is 1 function call
- chaining operation

example of where
encodeModified :: String -> [Modd]
encodeModified x = map toModd (encode x)
	where
		toModd (1,y) = Single y
		toModd (n, y) = Multiple n y

* `<-` - drawing elements **out of a list**, one at a time
* `let` - binding a single value to a name
If the right hand side is a list you want to iterate over, use <-, if its a computation, use let
