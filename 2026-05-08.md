### a)
Using:
```
Student(student_id, name, programme)
Module(module_code, title, credits)
Enrolment(enrolment_id, student_id, module_code, grade)
```

Query to compute each student's weighted average grade
```
SELECT s.student_id, AVG(e.grade * m.credits) AS weighted_average
FROM Student s
JOIN Enrolment e ON s.student_id = e.student_id
JOIN Module m ON m.module_code = e.module_code
GROUP BY student_id;
```

### b)
Query to list all modules where avg grade is below 50
```
SELECT m.module_code, AVG(e.grade * m.credits) AS average_grade
FROM Module m
JOIN Enrolment e ON m.module_code = e.module_code
GROUP BY module_code
HAVING average_grade =< 50
```

- There are several problems wih the second GET example that violate REST design conventions. REST endpoints should have noun names of only one word, so 'getPosts' breaks this as it includes a verb. Using query parameters in GET is not a good idea, as it is insecure - an attacker could change the value of the parameter to get into someone else's account.
