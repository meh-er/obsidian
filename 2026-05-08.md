### a)
Using:
```
Student(student_id, name, programme)
Module(module_code, title, credits)
Enrolment(enrolment_id, student_id, module_code, grade)
```

Query to compute each student's weighted average grade
```
SELECT s.student_id, AVG(e.grade * m.credits) AS weighted_average
FROM Student s
JOIN Enrolment e ON s.student_id = e.student_id
JOIN Module m ON m.module_code = e.module_code
GROUP BY student_id;
```
