#DAWP 

JSON Web Token (JWT) is an open standard that defines a compact and self-contained way for securely transmitting information between parties as a JSON object. Can be signed using HMAC or RSA
- Used in authorization: Once a user is logged in, each request will include the JWT, allowing the user to access routes, services and resources that token permits. 
- Single Sign On has small overhead and ability to be used across different domains
